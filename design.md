# UAC lab design

Audience: developer/operator running a local protocol simulation. Task: enroll, authenticate, issue and invoke one access grant. Tone: utilitarian. Genre: modern-minimal. Layout: workbench with a narrow identity rail and a main sequential operation panel; no marketing hero or feature tiles.

Use system sans-serif and monospace for machine values. Palette: paper #f4f3ee, ink #202722, accent #245c45, line #d8ddd4. Spacing is 4/8/16/24/32 px. No animation except a short opacity transition. Labels remain explicit. Show simulated authenticator and deferred hardware status. Buttons have focus, disabled, busy, error and success states. No invented metrics. Responsive layout stacks the rail above the workspace below 760 px.
