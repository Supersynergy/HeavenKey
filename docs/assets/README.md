# Bildquellen

- `heavenkey-title.webp` verwendet das ursprüngliche HeavenKey-Motiv eines
  goldenen Schlüssels vor einem leuchtenden Portal. Für die 0.32-Vorschau wurde
  das Motiv aus dem ursprünglichen Bild neu auf eine breite Titelfläche
  komponiert. Die Startseite und die Release-Beschreibung verwenden diese
  Fassung.
- `heavenkey-hero-square.png` ist die quadratische Fassung des ursprünglichen
  Motivs vom 12. Oktober 2026. Der Desktop-Tresor bettet sie für den
  Sperrbildschirm ein. Dieselbe Datei dient als Quelle für das macOS-App-Symbol.
- `heavenkey-hero.png` ist das ältere README-Titelbild mit Tresor-Symbol.
  `social-preview.jpg` und `social-preview.png` stammen aus früheren Ausgaben.
  GitHubs separate Social-Preview-Einstellung erfordert einen eigenen Upload.

Die Titelbilder sind Markenillustrationen. Aufnahmen der Anwendung sind unter
[docs/screenshots](../screenshots/README.md) dokumentiert.
